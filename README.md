# Weekly Reading Adventures

Text-draft checkpoint for an 8-week summer listening and reading project.

## Current Status

- 8 reading drafts are in `data/readings.json`.
- Week 1 starts on `2026-07-06`, and the site calculates each weekly date range from that date.
- `data/glossary.json` contains the built-in weekly dictionary.
- `index.html`, `styles.css`, and `app.js` provide the seven-step listening/reading workspace.
- Each reading targets 250-320 words.
- Article body text is English only.
- Listening and reading instructions are bilingual.
- Instructional UI is bilingual, especially buttons, task prompts, and learning workflow labels.
- MP3 files are not generated yet. Audio comes after text approval.
- GitHub Pages publishing comes after text and audio approval.

## Validate

```bash
npm run validate
```

Run the static site locally:

```bash
npm run serve
```

Then open `http://localhost:5173`.
